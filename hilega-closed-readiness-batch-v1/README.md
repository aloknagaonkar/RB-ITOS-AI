# Offline scoped installed-release readiness batch

Runs 99 previously separate cases against the current installed release where applicable: seed preflight 1, factory/private-context/provisioning/order-policy/timestamp 74, file transactions 8, structural account review 8, historical finance 8. This repetition follows deployment: it checks the installed module bytes, not merely the earlier staged candidate. It is a scoped regression, not full repository regression or proof of a real order path. Positive context tests use synthetic keys and in-memory gate overrides in isolated test processes; their conftest denies network connections. Pure file/finance suites do not invoke broker collectors.

The command calls only current installed status before and after; no broker GET is made, no production gate is opened, no application service is controlled, and no private authority is generated. All test databases/files are disposable. It reads the existing adapter metadata in SQLite read-only mode for account scope, never constructs a live Store. Installed release file hashes and factory-disabled registration are checked before and after.

The output combines the latest recorded finance result, a public authority review request, a conservative ORDER-POLICY-REVIEW.json marked unapproved and not installed/enforced, and an updated MILESTONES.md. Existing policy candidates are described for review; numerical allocation limits are not silently approved. Recorded historical evidence is not refreshed or re-certified. Unknown/null charge components are labelled UNKNOWN_COMPONENTS rather than a proved arithmetic mismatch. No absence of data is treated as zero fees or readiness.

Required arguments: --repo, --active-plan, --active-plan-sha256, --finance-review. The plan must describe the installed running closed Group 2 upgrade. Full broker timestamp clarification, actual fees, independent authority approval, runtime policy enforcement, fresh enrollment and final activation remain pending. Tests run on user VM only; local checks are syntax and ZIP CRC.
