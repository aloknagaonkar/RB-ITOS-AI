# After-hours authority/context preparation

Binds the actual deployed one-position release, account scope, module hashes, policy config and installed private-context field contract into one public review packet. Checks current upgraded status before/after and reads application/adapter tables only through read-only SQLite connections. It does not instantiate live Stores or import candidate activation code. It reads source AST for the field contract and unconditional hard gate. The status helper verifies existing bound configuration bytes for integrity; this review does not load an authority key, account pin or broker token for constructing a context. No credentials are exported.

No tests or broker captures are repeated. No random key is generated, no authority is approved, no owner is enrolled, no service is controlled and no controller is resumed. Review output lives in a private 0700 folder with 0600 files; MILESTONES.md copies the current deployed policy checklist and adds only evidenced review items.

The candidate provisioning helper is not a production trust issuer, and the gate remains unconditionally closed. A real trust path and factory activation/recovery integration still require implementation/review. This packet does not provide activation or enrollment; unresolved seed, lease, journal and private-file bindings are listed explicitly instead of being filled with fabricated values.

After-hours work is recorded as the user's requested context, not as a promise that the tool determines exchange schedules. Fresh seed enrollment remains a separate eligible-session step. Local checks: Python syntax/ZIP CRC only. VM command performs the actual read-only review.
