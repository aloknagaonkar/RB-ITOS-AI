# RB-0.9.4 — Execution Committee Dashboard

RB-0.9.4 changes the candidate analysis UI from a Rank-#1-centric inspection view into a committee-first dashboard.

## Changes
- Adds **Execution Committee Dashboard** showing every ranked candidate with probability, expected value, TSS, opportunity/historical scores, committee decision and reason.
- Rank remains discovery order only; it no longer appears as execution authority.
- Renames the single-candidate panels to **Candidate Detail** and **Rule/Intelligence Evidence**.
- Adds a selected-candidate **Institutional Execution Committee** detail block.
- Shows adaptive intelligence module confidence, learned weight and signed contribution for explainability.
- Keeps RB-0.9.3 decision/queue/lifecycle architecture unchanged.
- No fixed maximum trade-count rule is introduced.
