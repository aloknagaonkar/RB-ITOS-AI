# Combined preparation window review

Run `.venv/bin/python hilega-group2-window-review-v1/manage.py --repo "$PWD"`. Runs eight targeted tests on VM and existing closed-deployment status check. Pins the deployed controller and allocation implementation, takes SQLite read-only snapshots, classifies native resume prerequisites and creates an audit proposal.

No resume, migration, SQL mutation, service control, credentials, signal replay or funds injection. Standard resume calls the simulator allocation readiness gate. A preparation-specific bounded window and independent durable timeout recovery must be implemented and rehearsed before live apply exists. Missing binding/reservation tables can be normal before first atomic preparation. Prior 314-case regression is not rerun. Local verification is syntax only; behavioral tests are reserved for VM.
