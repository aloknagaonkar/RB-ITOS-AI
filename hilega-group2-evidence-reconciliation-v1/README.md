# Deployed Group 2 evidence and structural reconciliation

One command uses the current closed-upgrade PLAN and its digest, checks deployed status before and after, runs eight new structural account-review tests, then captures GET-only account evidence through the running source worker's existing read context. It reuses the earlier cross-endpoint capture client and compares order history with daily/per-order trades. The structural review checks order/trade identities and filled quantities, duplicate fills, nonterminal orders and position quantity schema. No prices, account IDs or order IDs are printed by the anonymous report. Raw signed account evidence and diagnostic logs remain private in a 0700 review directory with 0600 files.

No fee endpoint is called: fee components, cost basis, strategy ownership and net P&L remain unverified. Current-day evidence may be empty after a broker day rollover; that cannot clear a prior timestamp discrepancy. Cross-endpoint snapshots are sequential, not atomic. Any mismatch requires review and never authorizes a release or retry. No timestamps are shifted or defaults changed. No support message is sent.

Status writes only the existing review checklist; the new package writes its own private audit folder. No application SQL mutation, live controller resume, application service controls, authority generation or order submission occurs. A new MILESTONES.md copies the latest deployed checklist and adds only current audit evidence. The 74 candidate tests and eight earlier transaction tests are not rerun. Local validation is syntax and ZIP integrity only; tests run on the user VM.
