# Offline authority / private factory / pause recovery candidate

Implements a detached HMAC-SHA256 grant verification candidate against explicitly supplied trusted-root bytes. The trusted-root provider is external to the grant and is consulted on every poll. Exact account, release, position-policy, private-context, authority identity/key fingerprint, signed owner row, seed and source-lease bindings are required. Grants require explicit timezone-aware validity, maximum 24-hour lifetime, constant-time signature verification and production_execution_enabled false. Candidate issuer roots must differ from the authority signing key, account-capture key and broker-token bytes. No root, authority, grant or credential is generated by the package CLI.

AuthorityBoundFactory delegates through the actual deployed PrivateContextLoader and ExecutionSessionFactory. The unconditional installed hard gate runs before grant, trust or private-file providers. Where tests override that gate in memory, every poll revalidates trust/grant and private files/owner before calling the existing factory, even if its session is cached. Validation failure uses the existing native monotonic pause command and then raises; no new authority, enrollment, retry or resume is attempted. The explicit recovery adapter pauses without loading private context. Startup registry/reboot deployment is not modified.

The 22-case VM suite consists of 18 grant tests and four factory/recovery tests. Positive cases use synthetic roots, synthetic private files/databases, gate overrides in the test interpreter, and intercepted transports. Network connections/DNS are denied by the test conftest. Two synthetic full candidate cycles prove delegation through existing modules; they do not certify real order execution. The real gate test proves no provider is read with installed default behavior. Installed module hashes and closed-runtime status remain unchanged.

This is an implementation candidate, not a production trust issuer or deployed authorization system. No persistent root registry/file-loader, operator signing workflow, actual worker registration, configured-factory boot recovery or live authority provisioning is installed. These remain review/deployment work. Broker timestamp/fees and fresh real enrollment remain blocked independently. Full repository regression and prior tests are not rerun. The resulting checklist records only this scoped candidate validation. Local checks are syntax and ZIP CRC; behavior runs on the VM.
