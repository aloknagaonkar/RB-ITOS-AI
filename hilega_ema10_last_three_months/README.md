Run analyze.py --self-test then analyze.py from repository root. Inputs: existing EMA10 report.json. Outputs: monthly/window summary.csv, complete trade-details.csv, ema10-hurt.csv, ema10-helped.csv, excluded-entries.csv, report.json. Default window is rolling three calendar months ending at the latest eligible trade session; if latest is 2026-10-01 it is 2026-07-02 through 2026-10-01. --end-date YYYY-MM-DD changes the anchor; it does not add unavailable data. Each alternative policy remains separate. Trade details retain source entry, warning, exit prices/times, current and EMA10 points, giveback and earlier-entry gaps; waiting gaps remain unavailable. No broker calls or production changes. Existing output directories are protected; choose a new --output-root for reruns.
