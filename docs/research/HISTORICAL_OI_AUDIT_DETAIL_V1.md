# Historical OI Audit Detail V1

Adds an expandable Audit row to Historical OI Research.

Detailed audit includes:
- spot, moving ATM, fixed ATM
- CE/PE OI
- CE/PE delta OI
- CE/PE OI percentage change
- imbalance (PE delta - CE delta)
- activity and common strikes
- previous/current/change PCR
- CE/PE positioning state
- ATM CE/PE premium percentage change
- fixed-basket delta OI/activity/PCR
- +5/+10/+15 minute retrospective NIFTY research context

Forward returns are explicitly labeled retrospective and are not live features.
