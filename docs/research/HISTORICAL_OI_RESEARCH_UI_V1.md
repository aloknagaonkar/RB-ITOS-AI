# Historical OI Research UI V1

Exposes the existing 90-session historical OI evidence without conflating it with strict live-shadow replay.

Source: `data/historical-evidence/oi-pattern-library-90d-historical-only-v1.csv`

Verified: 90 sessions, 6660 rows, exactly 74 rows per session, 2026-05-04 through 2026-09-08.

Displays spot, moving ATM, CE/PE OI, CE/PE OI deltas, previous/current/change PCR, CE/PE positioning states, fixed PCR, and pattern family.

Strict replay readiness is unchanged.
