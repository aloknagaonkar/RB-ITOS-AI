# ALL3_STRONGEST_RUN_EXTRACTOR_V1

Extracts the five strongest persistent BULLISH_ALL_3 runs from the frozen bullish cohort
and the five strongest persistent BEARISH_ALL_3 runs from the frozen bearish cohort.

Ranking:
1. longest exact ALL_3 run in candles
2. higher session mean expected-direction run length
3. higher total expected-direction ALL_3 candles

This is for manual chart validation only. It does not modify strategy logic or tune thresholds.
