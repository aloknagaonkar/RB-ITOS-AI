# V61 — Re-entry necessity / second-leg exit comparison

V58 reconfirmed CAP20 strongly.
V59/V60 showed that existing re-entry triggers are often followed by meaningful
favorable excursion, but completed second legs give back too much before the
structural terminal.

V61 directly compares:

1. CAP20 only, no re-entry.
2. Current re-entry management.
3. Fixed re-entry timestamps with a small set of transparent second-leg
   protection policies.

This is an exploratory comparison, not a production-rule selection exercise.

Important:
- The sample contains only 9 re-entry events.
- Open second legs are reported with a session-end mark for full-sample
  descriptive comparison.
- Current strict structural-terminal results are also reported separately.
- No B/E entry, CAP20, or re-entry timing rule is modified.
