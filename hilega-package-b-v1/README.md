# Package B — combined authority, private context and enrollment/recovery candidate review

One command: `.venv/bin/python hilega-package-b-v1/manage.py --repo "$PWD" --broker-read`. Requires the installed/running closed recovery transaction and Package A code. It verifies the existing recovery status before and after the run. No live arming, authority provisioning, owner enrollment, service control, gate change or application SQL mutation occurs.

The 40-case batch consists of the previously implemented factory (10), private-context (14), provisioning/recovery (10), and new public handoff contracts (6). Application modules come from the approved immutable deployed backend/runtime, not the installed checkout. Fixture helpers are bundled with this package. Pytest runs with a new private basetemp, a minimal environment, external plugin autoload disabled and real socket/DNS connections denied. Positive legacy candidate tests temporarily override the gate in memory and intercept transports only inside that isolated synthetic test process. Installed gate/source bytes are reverified unchanged. The batch covers private permissions, expiry, independent candidate keys, signed ownership, context/source/lease binding, first-seed commit, interrupted commits, recovery, and candidate cycles. It does not certify production authority.

Optional --broker-read invokes only the running source's existing configured_evidence GET provider, using explicitly selected environment values from that exact owned worker process. It validates the signed market/cash bundle and account-pin/adapter scope, saves evidence privately, and prints only a limited result. No private authority is loaded and no plan/request is created. Raw credentials are not printed or saved. A read-context/market-data failure is reported separately from passing synthetic tests.

Outputs: RESULT.json, a public-only AUTHORITY-REVIEW-REQUEST.json and CONTEXT-ADOPTION-PLAN.json. A locally generated random key is not treated as production trust. No key is created. Live preparation stays blocked until trusted authority/policies and the closed context-registration/recovery binding are reviewed: first-seed enrollment requires a fresh post-resume signal within 60 seconds, so arming before the handoff is ready would create avoidable stale state. The original hard-gated provisioning path remains closed before private I/O.

Source provider preflight may be blocked by real broker/market evidence; this is not permission to relax validators, rotate credentials or open the gate. Full repository regression is not rerun. Behavioral tests run on your VM only; local checks are syntax/archive only.
