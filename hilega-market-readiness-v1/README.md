# Combined market evidence read check

Run from the VM repository using the active registration rollout plan.
Reads the verified sealed-release journal reader, cached operational warmup assessment and existing active option quotes. Verifies closed runtime before and after and queries controller mode read-only. No HTTP requests, credentials, cache repair, subscription writes, replay, service control, enrollment or resume. Only a new private audit folder is written.

Warmup is a cached monitor assessment, not an independent indicator replay. Quotes cover existing subscriptions only; expiry presence and lot schema are not full instrument identity verification. Required strategy contract coverage remains unverified. No fresh entry signal is required to validate the source clock. Missing/stale evidence is reported for review. The report is not an activation approval.

Local validation: Python syntax and ZIP integrity only. Execute on the VM for actual evidence.
